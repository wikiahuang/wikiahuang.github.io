# Weiqi Huang's Academic Website

Source files for [wikiahuang.github.io](https://wikiahuang.github.io/).

## Structure

- `index.html`: personal homepage and publication list
- `assets/`: shared styles, scripts, icons, and images
- `floverse/`: FloVerse project page
- `research/`: research page
- `AboutMe/`: about page
- `future-goals/`: future goals page

The repository contains deployable static HTML. GitHub Pages serves it directly
from the repository root.
